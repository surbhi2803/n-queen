# ♛ N-Queens Visualizer

An interactive web-based visualization of the classic **N-Queens problem**, built using **HTML, CSS, and JavaScript**.

This project not only solves the problem using backtracking but also **visually demonstrates how queens are placed on the board**.

---

## 🌐 Live Demo  
👉 https://n-queen-two.vercel.app/

---

## 🚀 Features

- ♟️ Interactive chessboard UI
- 🔍 Solves N-Queens using **Backtracking**
- 🎨 Clean and responsive design
- ⚡ Dynamic board generation for different N values
- 👀 Visual representation of solutions

---

## 🧠 Problem Statement

Place **N queens on an N×N chessboard** such that:

- No two queens are in the same row  
- No two queens are in the same column  
- No two queens attack each other diagonally
